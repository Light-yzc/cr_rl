# 昂贵实战轨迹的长期复用：离线RL研究与落地建议

## 修正方向

用户强调真人实战交互成本高，不能只按“有限PPO更新后立即重采很多局”安排长期路线。有限PPO仍是小预算基线，但长期复用同一批数据应作为offline RL问题：固定实战数据集 + 受约束的策略改进 + 少量新对局验收。这里是研究结论和建议，未实现IQL/AWR/CQL训练器。

## 已读取的一手来源

1. Peng et al., Advantage-Weighted Regression (AWR), 2019。先回归价值，再用优势加权的最大似然拟合数据动作，支持离策略replay和纯固定数据实验。https://arxiv.org/abs/1910.00177
2. Kostrikov, Nair, Levine, Offline RL with Implicit Q-Learning (IQL), ICLR 2022。使用expectile V、数据动作上的Q备份、advantage-weighted policy extraction，避免训练时查询数据分布外动作的Q。https://arxiv.org/abs/2110.06169
3. Kumar et al., Conservative Q-Learning (CQL), NeurIPS 2020。针对固定数据下分布偏移导致的Q高估，通过保守价值正则约束策略改进。https://arxiv.org/abs/2006.04779
4. Nair et al., AWAC。已有离线数据 + 在线改进，包含非最优数据和真实机器人实验；不是把失败对局直接当专家BC。https://awacrl.github.io/ ; https://arxiv.org/abs/2006.09359
5. Nakamoto et al., Cal-QL, 2023。离线保守价值训练后在线微调可能先退化，价值尺度校准有助于衔接；并非取消后续交互。https://arxiv.org/abs/2303.05479 ; https://nakamotoo.github.io/Cal-QL/
6. Ball et al., Efficient Online RL with Offline Data (RLPD), ICML 2023。利用旧数据提高在线采样效率，强调实现细节；仍属于在线方法，不可当作100局后永不采样的保证。https://arxiv.org/abs/2302.02948

上述方法的基准主要为D4RL、控制与机器人，不是已在当前版本皇室战争、当前观察/动作空间和百局数据量上验证的现成答案。

## 建议：AWR小基线，IQL作为长期候选

首轮不要直接替换生产PPO。保留冻结原策略和有限PPO结果作为基线，新增独立离线训练分支：

- 最小AWR-style基线：利用完整局回报和固定/交叉验证的价值基线给实际动作加权。适合复用现有V与分层Actor，但单次实际回报噪声大、对手强弱混杂，不是可靠因果动作评价，也不自动保证策略改善。
- 长期优先评估recurrent IQL：保留原生分层Actor和时序状态；另训练Q(h,a)（可用双Q/目标网络作为实现选择）与V(h)。h由该模型用从开局的观测前缀重建；动作含WAIT、卡槽+落点和技能，不假装只看一个孤立状态。Q(h,a)可以用时序上下文和选定动作特征计算一个标量，而不是新增每步搜索全部2307动作。
- IQL的V拟合数据动作Q的上expectile；Q使用真实奖励和下一时序状态V备份，真实终止不bootstrap，按实际tick长度折扣。策略通过裁剪的exp((Q-V)/beta)权重拟合数据里的动作。负优势通常意味着更低的正训练权重，不是直接将所有输局动作概率取反。
- 现有Critic只有V(h)，没有Q(h,a)，必须新增并验证；不能把当前V乘权重包装成“已实现IQL”。Q/V历史需要分别在当前权重下从真实前缀重建；不能跨对局共享记忆或把随机裁片当无历史状态。
- 初期可冻结Actor大部分骨干/仅适应小模块以限制百局过拟合和资源使用，但这会限制能学到的东西，需与解冻部分层的版本做对照。通过推理old_logp复现不等于离线Q拟合正确。

## 数据究竟怎样纠正行为

例子：相近局面中，一些轨迹提前花5费后遭反打；另一些保留费用后有效解场或完成组合。完整后续奖励给Q/V估计提供监督，离线策略训练提高估计更有利的真实动作的相对权重。胜局与败局都需要；败局有好操作，胜局也可能有坏操作。

如果数据中无压力时几乎从不等到6费，算法对“此时再等几秒会怎样”缺少直接证据。函数泛化可能有帮助，不能凭空创造可靠反事实；100局训练1000轮也不增加动作覆盖。需要有针对性地补覆盖，来源可以是少量操作者接管的完整轨迹、单独标明行为版本的留费探索分支，或便宜模拟器中重新生成对应局面。来自不同策略的数据可用于适合的离线方法，但不能冒充同版本PPO样本。

只有终局win/loss时，不能“胜局所有步权重大、败局所有步权重小”就声称学会错误归因。还要避免以折扣后的负终局回报无条件比较“拖到更晚输”的轨迹，学出拖时间捷径。

## 数据与验证安排

- 当前60局及后续100局永久归档，版本/卡组/等级/结果/控制器干预分层，固定整局train/validation划分。对手隐藏手牌和水不需要补全，但可见历史需保留。
- 收集策略的proposal语义、门控和真实执行继续区分。确认未执行的开场动作不作为成功部署标签；保持Actor训练mask和时序上下文。离线方法理论上不依赖PPO old_logp，但仍需行为身份及干预信息保证定义一致。
- 不用旧数据的“离线预测胜率”代替新对局。约100个独立episode对超大模型很小，离线loss下降、Q变大都不能证明真人更强。固定模拟器外部对手能便宜地筛严重退化，但实机存在域差，最终仍需小批新实战验收。
- 候选限制为少量版本：原策略、有限PPO、AWR-style基线、IQL。先按留出整局价值误差、Q尺度、行为KL、按卡组动作覆盖筛选，之后用相同新对局预算比较；小样本只用于排除大退化，不宣布微小胜率提升。
- 不因为换成offline就承诺可任意增加Actor epoch。训练可长期复用，但每次更新仍需正则、留出测试和早停。epoch/step预算由合格数据量和上述验证确定，不预先承诺100局能充分训练183M模型。

## 便宜模拟器怎么参与

真实轨迹指出可复现的问题类型（5费时乱交法师/大军，随后空防），在模拟器从合法开局重新生成相似对阵和不同策略分支，用便宜rollout比较留费与投入的结果。实机obs不是模拟器完整state，不能直接灌进去做精确分支。

模拟器训练与实战离线训练分开记录来源、动作语义和reward。简单把两者混到一个replay并认为动力学完全一致会引入偏差。可以先交替更新/策略约束作为工程消融，不在未评估前宣称已解决sim-to-real。

## 结论

数据昂贵时，推荐方向是固定实战数据的离线策略改进，而不是无限PPO复读。IQL比直接大幅改PPO更值得作为长期候选；AWR-style是实现成本较小的基线。两者都依赖数据覆盖和价值可信度，无法保证只用失败轨迹产生从未出现过的正确攒费策略。少量针对性新轨迹应花在补缺失行为，而非盲目重复采样。
