# 100局实战轨迹的数据复用预算

状态：论文复核后的试验建议，不是已验收参数；未变更正在采样的策略。输入必须为通过终局、行为身份、动作概率和时序校验的完整对局，赢/负/平都保留。100局“录制完成”不代表100局训练合格。

## 数据量与step含义

2026-11-17审阅当前批次已完成的7局第2套卡组：每局平均380.86帧、95.86个action_ready/policy_wait帧。按同分布粗估100局为38,086观测帧、9,586个自由决策帧。此样本只有一个卡组，不能假定另一套相同，也不能把这些时间相邻帧当成同样数量的独立样本。实际训练以mask校验后的计数为准。

首轮按整局、两卡组分层固定80局训练/20局离线诊断。约30,469训练帧、7,669自由决策帧。验证局不进入Actor或Critic拟合，作用是监测价值误差和分布外推；用旧策略采到的验证局无法直接测新策略胜率。最好在冻结批次前分配划分；不要依据输赢反复挑选划分。

这里的step指optimizer.step成功提交，不是读了一帧，也不是完成一次epoch。Actor有效batch约512个选择帧，理论一遍约15步；整局BPTT不切碎轨迹以凑512，实际分组会超过目标，故需记录真实步数。80个完整episode仍远比3万独立样本少。

## 首轮建议

| 项 | 建议起点 | 依据/边界 |
|---|---|---|
| 采集 | 冻结同一Actor，温度1，0.4秒观察，约100个合格完整对局 | 不能采集过程中改温度或权重后混成一个behavior |
| Actor | 先4 epochs，最多8；16仅作为独立实验上限 | 约60—120个提交步，整局分组后实际可能更少；不是承诺必须跑到这些数字 |
| Critic | 先8 epochs，最多16 | 独立Critic可比Actor多复用，按留出整局的实际回报误差停止 |
| Actor LR | 1e-6起，候选0.5e-6/2e-6各自从同一起点分支 | 和近期约2.6e-6学习率相比更保守；同一数据上多次搜索会过拟合选型指标 |
| Critic LR | 1e-5起 | 新域终局稀疏奖励需适应；不能只增加value loss系数 |
| Actor有效batch | 512个有效选择帧 | microbatch1整局，梯度累积；VRAM实测后再增大 |
| Critic有效batch | 2048个有效状态帧 | 全部真实状态保留，包括WAIT与Actor排除帧 |
| 卡/落点熵 | 首轮沿用0.003/0.0005；后续单独试卡熵0.001 | 不同时改采样温度、熵和训练课程 |
| gamma/Actor lambda | 0.9995 / 0.985 | 真实tick间隔参与折扣；其合理性仍需回报归因检查 |
| Critic目标 | 真人终局奖励为+1/-1/0，完整局lambda=1作为该试验的目标设置 | 与原模拟器shaping域不同，清楚记录；完整终局无需伪造bootstrap |
| 冻结行为KL软约束 | reference系数0.02为起点 | 独立于BC锚点；实战单边训练无需为了这个约束上传BC模型 |
| PPO clip | 0.2 | clipping并非保证不偏离；必须配合整批分布检查 |

训练之前冻结行为分布与old_values/advantages，不得每epoch把当前策略的logp当成old_logp“刷新数据”。若先做Critic适应，避免使用拟合后残差几乎为0的同数据目标直接制造新Actor优势；保留冻结快照基线并单独记录MC价值拟合阶段。Critic进步不会自动改变独立Actor。

## 停止条件比固定epoch重要

每个Actor epoch结束，用全部训练选择状态和固定留出状态重建当前/行为分布，统计旧行为到当前策略的整批前向KL、卡KL和条件落点KL；不要用训练时某一minibatch均值冒充整批结果。建议先把选择状态均值卡KL约0.01、条件落点KL约0.02设为试验警戒，保留分位数、按局指标和实际clip比例，不把这些阈值当作皇室战争论文结论。超过警戒停止Actor进一步复用并保存上一个合格epoch，不能靠调高门槛强行跑满8轮。

现有优化器的reference_kl使用的估计方向和新整批前向KL仪表盘应明确标注，数值不可直接互换。当前engine按group做KL控制，新增整批epoch控制尚待开发。clip比例持续升高、有效优势信号被裁掉、留出价值误差恶化均提示不应继续。Actor loss下降不是独立停训/选模依据；留出旧轨迹也不能提供无偏的新胜率估计。

选型：先输出epoch1/2/4，只有整批KL仍小且诊断正常才延长到8。不把同一个100局重开10次、每次都把训练后权重当成新的采集策略。旧数据仍可保留做行为回放、价值诊断与未来off-policy研究。

## 数据稀缺的长期路径

1. 当前阶段优先有限多轮PPO + 更充分的独立Critic拟合 + 不改变对称/几何语义的输入优化，不急着重写算法。
2. 需要跨很多版本长期复用全部实战时，评估GePPO这类有off-policy修正的算法，必须保持每个采样版本概率、版本距离和真实终止信息。它不是把PPO epochs加到100。
3. IMPALA/V-trace适合处理actor与learner不同步，可作为未来架构参考；不保证很老的数据和任意大策略偏移都安全。AWAC偏向用离线数据启动再在线改进，需要合适的动作价值估计；不能仅用当前V(s)替代Q(s,a)就宣称实现。
4. 连续采样昂贵，可以分批适应：例如第一版100局，更新后采下一批20—30局检查与继续，旧局留档。新一批小样本不够判断细微胜率变化，可跨多个固定评估窗口累计证据。
