训练已正常完成原定至少1258场预算：最新182号、1268场、1340419个Learner样本。
以下探针在训练退出后的空闲双V100上运行，不增加生产训练、不回写权重、不混入BC。
本轮没有启用新的生产加速项，不能把候选局部时间减少说成整轮已提速。

## 当前 V100 / FP32帧编码的帧去重复验

旧L4去重候选参数误差曾9.44e-5失败。本次用当前182号、`frame_encoder_fp32=True`，
直接走现有PreparedHistoryBatches与model frame_indices可微gather路径；仅共享原始输入，
不跨更新缓存特征。随机种子20261109，从合法、有效且完整包含128历史的行随机取64条。
有效batch64、微批16、三步非零Adam，baseline与候选各重复；未改变LR/奖励/历史/目标。

既定门限保持：输出最大差<=.01，梯度cos>=.999，最终参数最大差<=1e-5。
