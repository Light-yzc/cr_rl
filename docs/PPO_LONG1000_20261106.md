# 新增1000场：采样/优化配比调整与运行交接

用户明确要求开L4继续长训，并选择新增1000场、独立评估48场。
这是一项训练配置实验，不承诺更快收敛，也不把旧288/300场实验改写成已完成。
不开subagent。新运行 `122m_long1000_sample2x_20261106`，会话 `ppo_long_l4_20261106`。

## 训练策略判断

旧PPO链路总体合理：on-policy数据、完整GAE时间轴、独立Critic、choice-only Actor、
Card/Tile KL及clip保护、历史池/BC参照均应保留。旧的两遍并不反常，
但在每轮仅3–5个新终局且Critic占主要计算时，增加重复训练未必是最有效投入。

最新审计说明：Actor不是冻结，Critic也有一定预测能力；关键动作的可选状态极少。
因此这次把计算预算向新采样倾斜，改变采样/优化比，不增加战术名单或高费奖励。

| 项目 | 旧阶段 | 新阶段 |
|---|---:|---:|
| 环境数 | 2 | 2 |
| 每环境采样决策步 | 1536 | 3072 |
| 每轮环境总决策步 | 3072 | 6144 |
| Actor最多遍数 | 2 | 2 |
| Critic遍数 | 2 | 1 |
| 微批量×累计 | 8×8 | 8×8 |
| 有效优化batch | 64 | 64 |
| Actor LR / Critic LR | 1e-5 / 1e-4 | 保持 |
| gamma / Actor lambda / Critic lambda | .9995 / .993 / .995 | 保持 |
| Card/Tile KL / grad clip | .015 / .06 / .5 | 保持 |
| 观测历史 / 决策频率 | 128帧 / 0.25秒 | 保持 |

同样数量新数据，Critic训练呈现次数减半；每次参数更新阶段看到约两倍新数据。
因一轮数据翻倍而Critic只训一遍，**每轮Critic总优化步数预计近似旧轮次**，
不是总计算量不变：采样和Actor工作量会增加，每轮可能更长，但每个新样本成本可能下降。
不把更长的采样窗口当成历史长度翻倍，模型仍看滚动128帧。
较长rollout减少参数更新边界，也可能让更多完整比赛属于同一behavior版本。

代价：Critic每条新数据只有一次拟合，可能欠拟合；Actor每轮更多样本可能更早触发KL保护；
策略刷新频率按环境决策步减半。必须检查真实吞吐、目标/MC误差与固定对手得分。
不为避免早停临时抬高KL或clip，不从“loss更高”直接判定退化。

这不是严格单因素因果试验：rollout长度和Critic遍数是一组同时注册的预算调整。
不能将之后胜率的变化只归因于其中一个参数。没有同预算双臂训练来证明收敛率改善。

## 预算、对手与评估

从旧完整84号恢复，原全局累计288场；原counter(origin18)为258，
新阶段目标counter>=1258，即新增至少1000场、全局至少1288场。
双方当前策略控制的一局仍只计一个完整对局；故障、截断、未完片段不计。
旧实验仍为288/300、44/48，未追加旧阶段12/4，也未声称旧预算已结束。
并行环境同一步终局可能造成最小目标的有限超出，必须报告实际场数。

对手保持30%当前双座位自博弈、50%历史PPO、20%BC；继承84号8个对手条目及胜率信息，
沿用历史快照间隔20000有效样本、池容量8。每局按概率抽样，实际比例会波动。
卡组池保持12套，合法英雄/进化形式保持，不再叠加人工攒费/护兵/目标偏置。

48场为新阶段独立预算：

- 过程36场：新增[20,60,100,200,350,500,650,800,900]场后，各4场/2对换边。
  对手依次轮换起点84、stable6、BC，共各3次；每个对手重复同一pair0–1与固定种子，便于看过程变化。
  重复配对不是独立新增胜率样本，不能把过程各快照合成最终模型胜率。
- 最终12场：新增1000场达到后冻结同一最终checkpoint，分别对三个对手各4场，
  使用未在本阶段过程短测用过的pair2–3。每个对手新阶段总计16场，预算合计48。
- 每个probe保存evaluation、原生命令重演审计及GUI `all_matches.jsonl`，无故障/原生结果一致才入账。
- 100场生成健康报告，包括当前目标诊断和最新probe；仅4局的短测不自动判胜负，
  不自动晋升、不因一场全败就改超参数。数值/故障/版本不变量失败则中止并保留备份。
