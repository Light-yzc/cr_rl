# 0.4秒WAIT比例与动作完整性复核（2026-11-10）

**当前执行以[STATE_EVENT040_TRAINING_20261110.md](STATE_EVENT040_TRAINING_20261110.md)为准。** 用户最终要求保持0.4秒、仅压缩WAIT并后移动作，已改用原BC记录离线重采样，293局/21057非WAIT标签完整保留并实际开训。本页下文是先前原生重新模拟的失败审计，不是停止新离线阶段或回退0.25秒的指令。

旧版逐行合法性使用流式mask检查，未解压全observations；新版逐局读取小型labels/masks。对齐0.4重建接受集中的同一173个原训练对局identity，不把175→173的对局删减当成间隔收益。

WAIT行数减少约39.8%，但动作也少238个（约2.05%）。这不是纯粹合并WAIT：新版还换了后端并重新模拟，时机、提前终局和合法性筛选都会影响。不能把全部差异归因网格间隔，也不能声称现有重建是动作无损。

当前timing目标prior0.20，按训练实际q≈0.06468计算动作权重≈3.092、WAIT权重≈0.855；选牌和落点另按对应标签数归一化。因此原始93.5%WAIT数量并非未经校正地压满时机目标。但每个seat等权，不能将该目标简单称为严格全帧自然分布。

## 用户新增硬约束

用户要求WAIT可以合并，但全部动作必须保留。动作包括普通出牌与技能，不能覆盖碰撞动作、跳技能，或把无法执行的动作静默删除。

固定8tick且每座位每次单动作的最小因果映射：

`assigned_tick = max(ceil(source_tick/8)*8, previous_assigned_tick_for_this_seat+8)`

动作向后取整，正常网格等待0～7ticks，即0～350ms；同座位碰撞按原顺序后排，延迟可能更大。提前取整会把原动作监督到更早的手牌、圣水和敌军状态，特别会污染法术时机，不采用。不同座位允许同tick提交。

原始293局25004个命令在纯网格计划里有102次同座位碰撞，FIFO可保留，计划额外排队最大8ticks。原实际执行器还按座位等待native确认（通常20ticks，在8tick网格上可到24ticks），属于额外延迟，并非0.4网格本身要求。修正应只受真实pending/费用/同牌合法性约束，不把不同牌人为串行等待到执行确认。

## 当前运行已停住

复核发现旧准入以source_or_native_terminal_completed为成功，接受正常提前终局的部分源动作轨迹；还设置skip_unavailable_abilities=True。

当前288接受局共24497源动作，仅20132个native成功确认，保留率约82.18%；130局完整执行全部源动作，其余158局提前终局，缺4365动作。全293局共有4371源动作未确认，故大部分缺失不是102次网格碰撞。

本轮新架构试验已停止，保留Drive完整update256恢复点（2187266827字节），状态action_integrity_hold，不自动续训。源BC、原始parquet及旧数据没有改动。该模型仅为不合新数据协议的试验记录，不自动晋升。

接下来先修严格重建与审计：每个源动作都须一对一对应native成功确认和唯一、合法、有效的监督行；技能不得跳过。提前终局造成后续动作无法执行时，整局转换失败并保留原始事件及原因，不伪造终局后的动作。

**整局转换失败不能冒称全部原数据都保留。** 若严格0.4网格导致无法转换的局，原始局/命令仍保留在source中，但不能把它们算作已进入新训练集。要所有局、全部原始时机都不变，需要保留更细时间尺度或另行设计不等间隔/多动作表示；固定0.4秒单动作接口本身不能保证这种无损转换。

在严格重建的真实覆盖率报告出来前，不恢复原0.4部分轨迹的长训，也不自动通过简单过滤扔掉大量对局后宣布完成。

## 严格重建的最终结果

移除全座位native确认锁、禁止技能跳过并加入逐动作映射后，完整293局真实JVM重建已完成：

- 143局通过逐局全部动作保留门禁，147368行。
- 这143局包含9580条原命令，确实逐条保留；但只占原始25004条的38.3139%。
- 其余150局转换失败，其全部原命令和执行原因保留在外置audit中，没有伪造后续标签。
- `strict_subset_ready=True`仅表示该143局可以分析；`training_ready=False`、`all_selected_source_commands_preserved=False`明确禁止自动开正式训练。

因此这次修改修好了调度和准入，**没有达成所有原始局／动作都进入0.4训练集**。不能拿143局内的100%冒称全数据无损。原0.25数据、原始parquet、旧BC和update256试验恢复点均保留。

当前选择：动作映射只允许后移、不提前；固定网格无法完整转换的局保留原始数据，停止自动续训。若用户要求全部原动作也全部用于训练，优先保留已有动作时间尺度，另行设计仅对等待进行压缩的表示；该表示会改变时间间隔语义，需要独立验收，不是继续丢动作换间隔。
